# Voice-enabled Tracker of NORAD-classified space objects around Earth

**OrbitSim AI** is a containerised satellite exploration demo, that presents orbital data of human-made space objects around Earth as an interactive **3D globe** or a **local sky view**, and answers your questions on when to look up. You can track satellites by name or **NORAD catalogue ID**, learn about upcoming passes over your location and inspect the MCP tool calls behind each interaction.
